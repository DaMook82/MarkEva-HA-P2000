# MarkEva P2000 — experimental development fork

This branch is a personal-use development checkpoint, not a tested installation or migration. It is based on the MIT-licensed upstream P2000 integration by cyberjunky and contributors. There is no tested installation route or support guarantee for this candidate. Read the [README](README.md) for scope, safety limitations and outstanding acceptance tests. The historical upstream YAML documentation is retained separately and does not describe a tested installation of this fork.
